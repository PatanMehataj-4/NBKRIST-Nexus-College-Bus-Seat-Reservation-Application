# 🚌 NBKRIST Nexus – College Bus Seat Reservation Application

## 📌 Project Description

NBKRIST Nexus is an all-in-one mobile application developed to simplify and digitalize the college bus seat reservation process for students of NBKRIST College.

The application provides a convenient platform where students can view bus seat availability and reserve their preferred seats in real time. It reduces the traditional manual reservation process and makes transportation management more organized, efficient, and accessible.

The application is developed using **Flutter, Python, and Firebase**, integrating mobile application development with backend services and real-time database functionality.

The project also includes a dedicated admin management system that allows college administrators to manage bus reservations, monitor seat availability, and handle transportation-related activities efficiently.

This is a real-world application designed to address an actual college transportation requirement. The application is currently live on the Google Play Store.

## 🎯 Project Objectives

## ⚙️ Application Workflow

1. Students open the NBKRIST Nexus mobile application.
2. Students log in to their accounts.
3. They view available buses and seat information.
4. Students select and reserve their preferred seats.
5. Firebase updates the reservation information.
6. Admins can monitor and manage reservations through admin features.
